# Online Shopping Platform Database Modernization (SQL Advanced Assignment)

## Overview
This repository contains the database implementation and advanced SQL query solutions for the **SQL (Advanced) Assignment**. The project models an online shopping platform experiencing rapid business growth, covering advanced joins, subqueries, set operations, window functions, common table expressions (CTEs), database views, indexing & execution plan profiling, stored procedures & functions, ACID transactions, database triggers, and query performance tuning.

## Project Structure
- `ecommerce_advanced_management.sql`: Master SQL script containing schema creation (DDL), sample seed data, and Tasks 1 through 20 across all 11 technical sections.
- `docs/`: Reference training material and assignment specification documents:
  - `docs/Training.Material.SQL (Advance).pdf`: Advanced SQL training material.
  - `docs/Training.Assignment.SQL (Advance).pdf`: Assignment instructions and task requirements.
- `screenshots/`: Visual execution evidence for all 9 required milestone deliverables.
- `README.md`: Comprehensive documentation, relational schema overview, ER diagram, concept mapping, and step-by-step execution instructions.

## Development & Review Workflow
In accordance with professional engineering standards:
- The complete assignment implementation is developed on the dedicated feature branch: `feature/sql-advanced-implementation`.
- Full task solutions, execution proofs, and expanded documentation are reviewed via a GitHub Pull Request (PR) targeting `main`.
